Classes of people writing code

September 1, 2026

There are classes of people writing code: people who were engineers, builders, and maintainers vs. people who are non-technical.

The serendipity of working code is a dopamine rush. That’s what non-technical folks are feeling now that they can get a working piece of software generated. But I think the bar for software has gone up now.

A real engineer generating code vs. a non-technical person generating a lot of code — the difference is huge. It is not the logic, but how you approach the problem. If you are just building a system of record, sure, it is not that different. But if you are solving a tech problem and have lived and breathed the problem before, you know exactly how to approach it.

The gap is wider than ever, as there is no learning involved now to code.

It is simultaneously the best time and the worst time to be an engineer.
